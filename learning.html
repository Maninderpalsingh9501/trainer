Learning Management System

Intellipat & AVPS

Tech Stack: Python-Django, Langchain, Pincecone, Node.js, AWS, Docker

I developed two types of Learning Management Systems (LMS): one for AVPS focused on internal training, and another for the edtech platform Intellipaat.

The system includes an LLM-based chatbot built using Meta’s LLaMA 3.1 to answer student queries interactively.

I also implemented a machine learning model for student behavior detection during online exams to identify suspicious activities.
The entire solution was containerized using Docker and deployed on AWS for scalability and performance.
